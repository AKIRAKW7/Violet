Preguntas frecuentes

¿Qué es Violet?

Violet es un bot multifunción para Discord diseñado para combinar entretenimiento, economía, sistemas sociales y herramientas para comunidades.

¿Violet es gratuita?

Las funciones principales de Violet están diseñadas para utilizarse directamente dentro de Discord.

¿Cómo puedo añadir Violet?

Utiliza el botón "Añadir Violet a Discord" para iniciar el proceso de autorización.

¿Dónde puedo ver los comandos?

Puedes consultar los comandos disponibles directamente desde Discord utilizando el sistema de ayuda de Violet.
